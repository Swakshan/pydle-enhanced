# Pydle Enhanced

[![Version](https://img.shields.io/badge/version-1.4-blue.svg)](https://github.com/Swakshan/pydle-enhanced)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-Supported-darkgreen.svg)](https://www.tampermonkey.net/)

**Pydle Enhanced** is a feature-rich Tampermonkey userscript designed to elevate your puzzle-solving experience on [pydle.net](https://pydle.net/).

---

## 📥 Installation

1. Install the **[Tampermonkey extension](https://www.tampermonkey.net/)** for your browser.
2. Click the link below to install the script directly:
   👉 **[Install Pydle Enhanced](https://github.com/Swakshan/pydle-enhanced/raw/refs/heads/main/pydle-enhanced.user.js)**
3. Confirm the installation when prompted by Tampermonkey.
4. Navigate to **[pydle.net](https://pydle.net/)** and enjoy the upgraded experience!

---


## 🌟 Features

### 1. 🕒 Access any game/puzzle easily
Pydle Enhanced allows seamless access to past puzzles. When navigating to historical games using URL parameters (e.g., `?game=1`)

<video src="https://github.com/user-attachments/assets/5c86c2d2-7e00-4256-bc0d-e84815f816be" controls></video>

---

### 2. 🔤 Real-Time Character Counter & Guardrail
Keep track of your Python solution size instantly as you type!
* **Live Character Counter:** Get a live character counter, without the need to run and check if your code has exceeded the character limit.
* **Character Limit Guardrail:** Pydle enforces a maximum limit of **250 characters**. If your solution exceeds this limit:
  * The character counter turns **red**.
  * The **Run** button is automatically disabled to prevent wasted attempts with oversized code.

<video src="https://github.com/user-attachments/assets/80bcbbb0-0399-4331-80da-d6a6bcd97b2a" controls></video>

---

### 3. 🎯 Dynamic Attempt Counter
Stay aware of your effort on each puzzle!
* Tracks and displays the total number of attempts submitted for the active puzzle.
* Increments dynamically every time you execute a valid solution.
* Persists accurately across sessions via local storage mapping.
